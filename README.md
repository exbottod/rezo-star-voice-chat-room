# REZO STAR

Android voice chat room app with live voice rooms, gifts, profile items, and mini games.

- Package name: `com.rezochatvoice.exceo`
- Platform: Android 7.0 (API 24) and newer, arm64-v8a + armeabi-v7a + universal APK
- Built with Kotlin and Jetpack Compose
- Voice rooms: LiveKit (self hosted)
- Account and login: Firebase Authentication
- Wallet, gifts, and store: Supabase
- Patch based in app updates, so users download only the changed bytes

## Features

- Live voice rooms with mic seats, seat locks, and room management
- Text chat with pictures, friends, and private messages
- Gifts, cashback gifts, and weekly rocket leaderboards
- Profile items: frames, chat bubbles, entry effects, banners, medals, badges
- Custom unique ID numbers you can search and release yourself
- VIP and SVIP tiers with exclusive items
- Mini games with in app coins. Coins are only for in app items and games, and cannot be exchanged for real money.
- Indonesian and English interface
